# Мастерская кофе: лэндинг

Одностраничный сайт на Node.js без внешних зависимостей. Ставить пакеты не нужно.

## Запуск

Нужен Node.js 18 или новее.

```bash
npm start
```

Откройте http://localhost:3000. Другой порт: `PORT=8080 npm start`.
Для разработки с автоперезапуском: `npm run dev`.

## Что нужно заменить перед публикацией

Контакты лежат в одном месте, в файле `config.json`:

| Поле | Что это |
| --- | --- |
| `instagramUrl` | Ссылка на ваш Instagram, например `https://www.instagram.com/ваш_ник/` |
| `instagramHandle` | Ник, как он показан на странице |
| `phoneText` | Телефон, как он показан на странице |
| `phoneTel` | Телефон для ссылки «позвонить», без пробелов и скобок, с `+` |

После правки конфига перезапуск не нужен, страница читает его при каждом запросе.

## Где что лежит

```
server.js          сервер (отдаёт public/ и подставляет контакты из config.json)
config.json        телефон и Instagram
public/index.html  разметка и тексты
public/styles.css  оформление, светлая и тёмная тема
public/app.js      кнопка «Скопировать номер»
public/favicon.svg значок сайта
```

Тексты, цены и сорта правятся прямо в `public/index.html`. Фото кладите в `public/`
и подключайте обычным `<img src="/photo.jpg" alt="...">`.

## Публикация

Подойдёт любой хостинг с Node.js: сервер слушает порт из переменной `PORT`.
Адрес `/healthz` отвечает `ok`, его можно использовать для проверки работы.
